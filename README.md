# MDtoHTML

Markdown ファイルを HTML に変換し、既定ブラウザで開く Windows 向けツール。

## 特徴

- **カスタマイズ性**: テンプレートを書き換えることで自分好みのレイアウトにすることができます
- **ワンクリック変換**: ダブルクリック、ドラッグ＆ドロップ、「プログラムから開く」のいずれにも対応
- **オフライン動作**: ローカルでレンダリング（外部ライブラリのみ CDN から取得）
- **シンタックスハイライト**: highlight.js によるコードブロックのハイライト
- **ライト/ダークテーマ**: ツールバーから切替可能
- **目次（TOC）**: 見出しから自動生成し、フローティングサイドバーに表示
- **GFM 対応**: テーブル、引用、ネストリスト、インラインコードなど
- **更新ボタン**: ツールバーの 🔄 で元の `.md` を再変換（`mdtohtml://` プロトコル登録が必要）

## 必要環境

- Windows 10 / 11
- PowerShell 5.1 以上（標準搭載）
- インターネット接続（marked / highlight.js を CDN から取得するため）

## 使い方

### 1. ダブルクリック

`MDtoHTML.bat` をダブルクリックするとファイル選択ダイアログが開きます。
変換したい `.md` / `.markdown` ファイルを選択してください。

### 2. ドラッグ＆ドロップ

`.md` ファイルを `MDtoHTML.bat` にドラッグ＆ドロップすると、即座に変換されます。

### 3. 「プログラムから開く」に登録

`.md` ファイルを右クリック →「プログラムから開く」→「別のプログラムを選択」から
`MDtoHTML.bat` を選び、関連付けすると以後ダブルクリックで変換できます。

## ディレクトリ構成

```
MDtoHTML/
├── MDtoHTML.bat                  # エントリポイント
├── scripts/
│   ├── Convert-MDtoHTML.ps1      # 変換処理本体（PowerShell）
│   ├── Register-Protocol.bat     # 更新ボタン用 mdtohtml:// プロトコル登録
│   └── Unregister-Protocol.bat   # プロトコル登録解除
├── templates/
│   ├── template.html             # HTML テンプレート
│   ├── style.css                 # スタイル定義
│   └── script.js                 # クライアントサイドのレンダリング処理
└── sample.md                     # 動作確認用サンプル
```

## 更新ボタンの有効化（任意）

ツールバーの 🔄 ボタンで元の Markdown を再変換できます。これにはカスタム URL
プロトコル `mdtohtml://` の登録が必要です（管理者権限不要、`HKCU` に書き込みます）。

1. `scripts\Register-Protocol.bat` をダブルクリック
2. 生成済み HTML ページを開いてツールバーの 🔄 を押す
3. 初回はブラウザが「アプリで開きますか？」と確認するので、`MDtoHTML.bat`（または
   `Windows Command Processor` 等）を選択して許可

解除する場合は `scripts\Unregister-Protocol.bat` を実行してください。

未登録のままボタンを押すと、ブラウザがプロトコルを認識できずに無反応またはエラーに
なります。その場合は登録スクリプトを実行してください。

## 動作仕様

1. 入力された Markdown ファイルを UTF-8 で読み込み
2. `templates/` 配下のテンプレートにプレースホルダ置換で埋め込み
   - `{{TITLE}}` : ファイル名（拡張子なし）
   - `{{STYLE}}` : `style.css` の中身
   - `{{SCRIPT}}` : `script.js` の中身
   - `{{MARKDOWN}}` : Markdown 本文
3. `%TEMP%\MDtoHTML\<ファイル名>_<ハッシュ>.html` に書き出し（UTF-8 / BOM なし）
4. 既定ブラウザ（HTTP プロトコル ハンドラ）で開く

Markdown のレンダリングはブラウザ側で [marked](https://marked.js.org/) が実行します。

## 出力先と自動クリーンアップ

変換結果は一時フォルダに保存されます。

```
%TEMP%\MDtoHTML\
```

変換実行時に、同フォルダ内の **60 分以上前の `.html` ファイルは自動削除** されます。
ブラウザで閲覧中のファイルが消えないよう、最近生成されたものは残す仕様です。
保持時間を変更する場合は `scripts/Convert-MDtoHTML.ps1` 内の
`Remove-OldOutputFiles -RetentionMinutes 60` の値を編集してください。

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| ブラウザが開かない | 既定ブラウザの設定（設定 → アプリ → 既定のアプリ）を確認 |
| コードがハイライトされない | インターネット接続を確認（CDN が必要） |
| 文字化けする | Markdown ファイルが UTF-8 で保存されているか確認 |
